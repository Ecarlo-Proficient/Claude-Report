How the tools connect, and what moves to the Synology

QuickBooks is the one source. The QBO mirror is the one read of it: every tool reads the mirror, and only the writers and the live QuickBooks reports talk to QuickBooks directly. After Phase 2 the green box runs on the office server; everything in the blue box stays on the Mac.

Rules the map depends on

  • One QuickBooks renewer per app. The server gets its own Intuit app; it never re-authorizes the Mac's app.
  • One mirror writer. The day the server takes the refresh, the Mac's refresh is turned off. The Mac reads a finished copy, never the live file over the share.
  • One writer per file. The day the AP/AR sync moves, the Mac stops running it. Both trackers live on the Accounting share, so no OneDrive bridge is needed.
  • Tools never import tools. Everything common lives in shared/, so a tool moves with shared/ and nothing else.
  • Who writes to QuickBooks: Pay in QuickBooks and Re-apply (ledger), the recode --commit, bulk close (never MFD), and the loans-to-subs reclass. All gated, all on the Mac.
