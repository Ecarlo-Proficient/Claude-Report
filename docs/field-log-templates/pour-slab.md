- [ ] Mix design matches plan (record mix ID per truck)
- [ ] Slump test passed (record number)
- [ ] Concrete placed within allowed time from batch (~90 min)
- [ ] Consolidated with vibrator — no honeycomb
- [ ] Screeded and floated per spec (trowel finish vs broom per plan)

- [ ] Curing method applied (blankets, cure compound, water)
- [ ] Tickets collected — all given to PM / AP

**Notes**
- Weather at pour (temp, wind, rain), yardage used vs estimate, any cold joints.
